# Font licences

The page is set in the **Liberation** family, rendered from glyph atlases
built at build time by `gen_fonts.py` from the system font files
(`/usr/share/fonts/truetype/liberation/`):

- Liberation Serif (Regular, Bold, Bold Italic)
- Liberation Sans (Regular, Bold)

Liberation fonts are released under the **SIL Open Font License, version
1.1** (https://scripts.sil.org/OFL). The atlas PNGs in this repository are
mechanical renderings of those fonts at fixed sizes; they carry no
additional restriction beyond the OFL.

No other third-party font, image, or asset is used. Every picture on the
page — scenes, map, motifs — is original artwork drawn in code.
